# 🚀 How to Test on Your Phone Using Expo Snack

Follow these simple steps to get the app running on your iPhone in under 5 minutes!

## Step 1: Install Expo Go on Your iPhone

1. Open the **App Store** on your iPhone
2. Search for **"Expo Go"**
3. Install the app (it's free)
4. Keep it installed - you'll need it in Step 4

---

## Step 2: Open Expo Snack in Your Browser

1. On your phone or any device with a browser, go to:
   
   **https://snack.expo.dev**

2. The Expo Snack editor will load in your browser

---

## Step 3: Copy and Paste the Code

### Option A: On Your Phone

1. Open this file on your phone: `SNACK_VERSION.js`
2. Tap and hold to select all the code
3. Copy it
4. Go back to Snack
5. Delete everything in the `App.js` file
6. Paste the copied code
7. Wait 2-3 seconds for it to process

### Option B: On Any Computer/Device

1. Open the repository on GitHub:
   https://github.com/rajivharlalka/Fokus/blob/cursor/remove-code-d737/SNACK_VERSION.js

2. Click the "Raw" button to see just the code

3. Copy all the code (Ctrl+A, Ctrl+C or Cmd+A, Cmd+C)

4. Go to https://snack.expo.dev

5. Delete everything in the `App.js` editor

6. Paste the code (Ctrl+V or Cmd+V)

---

## Step 4: Run on Your iPhone

After pasting the code, Snack will automatically start building the app.

### You'll see a QR code appear on the right side (or bottom on mobile).

**To run the app:**

1. Open the **Expo Go** app on your iPhone

2. Tap the **"Scan QR Code"** button

3. Point your camera at the QR code on the Snack screen

4. Wait 10-20 seconds for the app to load

5. **The app will open on your phone!** ✈️

---

## Step 5: Test the App

Once the app loads on your phone:

### Test Flight Search:
1. Tap **"🔍 Search Flights"**
2. Try searching for:
   - **AA100** (San Francisco to New York)
   - **DL200** (Los Angeles to Chicago)  
   - **UA300** (Chicago to London)

### Or Use Quick Search:
- Tap any of the "Popular Flights" cards
- View instant flight details

### Test Flight Tracking:
1. Open any flight details
2. Tap **"+ Track This Flight"**
3. Go back to home screen
4. See the flight in your "Tracked Flights" list
5. Tap it to view details again

### Test Flight Details:
- View departure/arrival times
- Check gate and terminal info
- See aircraft information
- View flight status

## Troubleshooting

### Problem: QR Code Doesn't Appear
**Solution:**
- Wait 10-15 seconds after pasting the code
- Look for "My Device" tab on the right (desktop) or bottom (mobile)
- Click "Run" button if needed
- Refresh the Snack page

### Problem: "Something Went Wrong" in Expo Go
**Solution:**
- Make sure you copied ALL the code
- Check that you deleted all old code before pasting
- Try refreshing Snack and pasting again
- Make sure your phone has internet connection

### Problem: App Shows Blank Screen
**Solution:**
- Wait 20-30 seconds for the app to fully load
- Check your internet connection
- Shake your phone and tap "Reload"
- Close and reopen Expo Go

### Problem: Can't Scan QR Code
**Solution:**
- Make sure Expo Go has camera permissions
- Try the "Enter URL manually" option in Expo Go
- Copy the URL shown above the QR code
- Paste it into Expo Go
