## 📱 Deploy from Your Phone

Yes! You can deploy directly from your phone!

### Step 1: Sign Up for Vercel

1. Go to: **https://vercel.com/signup** on your phone
2. Click **"Continue with GitHub"**
3. Sign in with your GitHub account
4. Authorize Vercel

### Step 2: Deploy the App

**Option A: One-Click Deploy**

1. Go to this URL on your phone:
   ```
   https://vercel.com/new/clone?repository-url=https://github.com/rajivharlalka/Fokus/tree/cursor/web-version-d737
   ```

2. Click **"Deploy"**
3. Wait 2-3 minutes
4. Done! You'll get a live URL

**Option B: From Dashboard**

1. Go to **https://vercel.com/dashboard**
2. Click **"Add New..."** → **"Project"**
3. Click **"Import Git Repository"**
4. Select **"rajivharlalka/Fokus"** repository
5. Click **"Import"**
6. Under **"Branch"**, select: `cursor/web-version-d737`
7. Click **"Deploy"**
8. Wait 2-3 minutes
9. Your app is live!

### Step 3: Visit Your App

After deployment:

1. Vercel shows you a URL like: `https://fokus-abc123.vercel.app`
2. Click it to open your app
3. Bookmark it or add to home screen!

## 💻 Deploy from Computer

If you have access to a computer:

### Quick Deploy (No Code)

1. Go to: https://vercel.com/new
2. Import from GitHub: `rajivharlalka/Fokus`
3. Select branch: `cursor/web-version-d737`
4. Click Deploy
5. Done!

### Deploy with CLI

```bash
# Install Vercel CLI
npm install -g vercel

# Clone repository
git clone https://github.com/rajivharlalka/Fokus.git
cd Fokus
git checkout cursor/web-version-d737

# Install dependencies
npm install

# Deploy
vercel

# Follow prompts:
# - Set up and deploy? Yes
# - Which scope? (select your account)
# - Link to existing project? No
# - Project name? flight-tracker (or whatever you want)
# - Directory? ./
# - Override settings? No

# Done! Your app is live
```

## 🔧 Customization

### Change App Name

In Vercel dashboard:
1. Go to your project
2. Settings → General
3. Change "Project Name"
4. Save

### Custom Domain

Want `flighttracker.com` instead of `.vercel.app`?

1. Buy domain (Namecheap, Google Domains, etc.)
2. Vercel → Project → Settings → Domains
3. Add your domain
4. Update DNS settings as shown
5. Done!

## 🆘 Troubleshooting

### Build Failed?

Check:
1. Selected correct branch: `cursor/web-version-d737`
2. Build command: `next build` (should be automatic)
3. Output directory: `.next` (should be automatic)

### Can't Access Deployment?

1. Check your Vercel dashboard
2. Look for deployment URL
3. Try incognito/private mode
4. Clear browser cache

### Site Shows 404?

1. Make sure deployment finished (2-3 minutes)
2. Check deployment logs in Vercel
3. Try redeploying
